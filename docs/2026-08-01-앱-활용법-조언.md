## 1. codex(gpt-5.6-sol) 답변

결론: "기능을 따로따로 쓰지 말고, 몇 가지 반복 동선으로 묶어라."

1. **검색을 앱의 현관으로 쓰기** — 다른 앱 보다가도 `⌘⇧8`로 전역 검색, cmdALL 안에서는
   `⇧⌘O`, 뭘 눌러야 할지 기억 안 나면 `⌘P`(커맨드 팔레트). 팔레트 안에 자료에 묻기·위키
   인제스트·관계도·학습도우미까지 다 들어있음.
2. **OCR은 필요한 폴더에만 켜고, 반드시 재인덱싱 버튼 누르기** — "스캔 PDF 속 글자"·
   "사진 속 글자" 둘 다 기본 꺼짐. 켜기만 하면 안 되고 그 폴더 옆 "재인덱싱"을 눌러야
   기존 파일도 검색 대상이 됨. ("질의 확장"은 이미 기본 켜져 있어 따로 안 켜도 됨.)
3. **"빠른 메모 → 위키 → 자료에 묻기"를 하나의 흐름으로** — `⇧⌘M`으로 생각날 때마다
   메모하고, 나중에 진짜 가치 있는 것만 위키에 인제스트(Claude 병합안 비교 후 적용,
   되돌리기 가능). 그 위키 폴더를 검색 인덱스에도 등록해두면 "자료에 묻기"가 출처까지
   붙여 찾아줌.
4. **학습도우미는 "교재 전체" 말고 "한 단원씩 반복"에 쓰기** — 범위(쪽수·제목) 고르기 →
   카드/문제 만들기 → 대화하며 이해 확인 → 괜찮은 것만 노트로 저장. 지난번 고른 교재도
   자동 기억.
5. **음악·영상엔 짝꿍 노트에 한 줄이라도 적어두기** — "왜 저장했는지·핵심 구간"만 적어도
   검색·자료에묻기 대상이 됨.

## 2. claude(claude-fable-5) 답변

1. **자동 저장을 켜라** — 기본 꺼짐(`Settings.swift` 75행, 켜면 30초마다 저장). 어제(8/1)
   강제종료로 "저장 안 된 탭이 있었으면 내용이 사라졌을 수 있다"는 실제 사고 기록 있음.
2. **AI의 좋은 답변은 "노트로 저장" 버튼을 눌러야 내 것이 된다** — Claude 답변은 앱이
   따로 보관 안 함(화면에만 표시, 닫으면 사라짐). 저장해야 내용 검색·자료에 묻기의
   근거로 다시 걸림.
3. **빠른 이동(⌥⌘M)에 진짜 자주 가는 폴더를 등록하라, 되돌리기를 믿어라** — 자동으로
   안 채워짐(직접 등록 방식, 레고 결정). 이동·복사 전부 기록 남아 배치 되돌리기 가능,
   영구 삭제 경로 자체가 없음.
4. **어제 보류한 "검수관" 아이디어의 80%는 이미 있는 기능 조합으로 가능** — ①공고문·
   증빙 폴더를 내용 검색에 등록 → ②"자료에 묻기"(⌥⌘A)로 "필수 제출 서류와 마감일이
   뭐야?" 질문 → 출처 번호 클릭으로 공고문 해당 쪽 점프 → ③두 폴더 나란히 보기로
   공고문↔작성본 대조 → ④양식 채우기(원본 안 건드리고 새 파일). 몇 번 해보면 "사건철"을
   진짜 만들지 판단할 실전 근거가 쌓임.
5. **학습도우미 템플릿을 실제로 1~2개 만들어라** — `studyTemplates` 기본값이 빈 목록,
   만들어두지 않으면 만든 보람이 없음.

보충: OCR 스위치가 두 개다("사진 속 글자"·"스캔한 PDF" 별개, 둘 다 기본 꺼짐 —
`Settings.swift` 121·125행). 이미지 쪽은 8/1 실기 확인 끝났지만 스캔 PDF 쪽도
켜져 있는지 확인해볼 만함.

## 3. kimi(moonshot-ai/kimi-k2.7-code) 답변

1. **파인더 대신 cmdALL 파일관리 기능을 본격 써라** — `⌥⌘M` 빠른 이동에 자주 쓰는
   폴더 등록 + 라이브러리 모드 다중선택 드래그로 Finder와 양방향 이동·복사. 전부 로그로
   남아 배치 되돌리기 가능, 영구 삭제 없음.
2. **Claude에게 문서 전체 대신 드래그한 부분만 보내라** — PDF·한글/오피스·마크다운
   미리보기에서 선택 후 우클릭 "Claude에게 물어보기"(선택 없으면 메뉴 자체가 안 뜸).
   500페이지 PDF를 통째로 보내던 기존 결함(2026-07-31 수정)을 피함.
3. **Settings → AI에서 모델(opus/sonnet/fable)을 상황에 맞게 바꿔 써라** — 한 번
   설정하면 Ask Claude·자료에 묻기·폴더 정리·스마트 라우팅 등 Claude 쓰는 모든 경로에
   자동 적용.
4. **학습도우미는 범위+템플릿+대화 조합으로 써라** — 쪽/제목 범위로 분량 줄이기 +
   자주 쓰는 지시를 템플릿으로 저장 + 마지막 교재 자동 복원 + 대화하며 공부하기.
5. **모르는 파일도 스페이스바로 미리보고, 사진·메일까지 검색에 넣어라** — `.pptx`·
   `.zip`·`.psd`·`.json` 등도 스페이스바 큰 미리보기(QuickLook 오버레이)+`←→`로 넘기기.
   `.eml` 메일은 제목·보낸사람·본문이 내용 검색에 자동 포함.

요약: "읽기 도구인 척하지 말고 파일 관리자+AI 질의 도구+학습 도우미를 한꺼번에 쓰는 것"이
가장 덜 쓰이는 여력.

## 4. 종합 — 세 답변이 겹치지 않게 서로 다른 각도에서 지적한 공통 결론

- **설정 기본값이 꺼진 채 나온 기능들을 직접 켜야 한다**: 자동 저장, OCR(사진·스캔PDF
  둘 다), Claude 모델 선택.
- **AI 답변·검색·위키·학습도우미를 따로따로 쓰지 말고 하나의 흐름으로 이어붙여야 한다**:
  빠른메모→위키인제스트→자료에묻기, 또는 문서선택→우클릭 Claude→노트로 저장.
- **어제 보류한 "사건철+검수관" 아이디어는 지금 있는 기능(검색 등록+자료에묻기+두
  폴더 비교+양식채우기)만으로 상당 부분 흉내 낼 수 있다** — 새 기능 없이 먼저
  써보고 판단해도 됨.
