- **왜**: 2026-07-29 구현·배포됐지만 수동 스모크가 안 끝났다. 화면을 두 칸으로 나누는 큰 기능이라 실기에서 처음 드러나는 문제가 있을 수 있다.
- **볼 것**: 두 폴더를 켜서 나란히 훑어보기 · 칸 사이 드래그로 파일 이동 · 칸 안 읽기 전용 미리보기 · "이 창에서 제대로 열기" 버튼으로 기존 탭에 열리는지.
- **어디**: `BrowsePane`·`DualPaneView`/`PaneView`·`PaneReaderView`·`DualPaneToggleButton`. 설계 `docs/superpowers/specs/2026-07-29-dual-pane-design.md`.

### 2. 사진 속 글자 검색 (이미지 OCR)

- **왜**: 2026-07-29 v0.9.418로 배포됐지만 실제 사진 파일로 검색해본 적이 없다. 기본값이 OFF라 켜야 동작한다.
- **볼 것**: 설정 > "사진 속 글자도 읽기 (OCR)" 켜기 → 글자 있는 사진이 든 폴더 색인 → 그 글자로 검색해서 사진이 잡히는지.
- **어디**: `AppSettings.ocrImagesEnabled` · `ContentExtractor` 이미지 분기 · `OCRService.loadCGImage(from:)`.

## 다음 — 사소한 후속 (조각 A 재검사에서 나온 것)

동작에 문제는 없고 다듬을 여지만 있는 것들. 급하지 않다.

### 3. 심볼릭 링크 파일이 내용 색인에서 빠진다

- **왜**: 링크로 연결된 파일은 폴더 색인 대상에서 제외된다. 흔한 경우는 아니지만 찾던 파일이 안 나오면 이유를 모른다.
- **어디**: `SearchIndexer.indexFolder` 의 파일 열거 부분.

### 4. 사이드바 즉석 검색이 아직 md·txt만 본다

- **왜**: 폴더 안에서 바로 하는 검색은 FTS5 내용 색인과 **다른 경로**라, 내용 색인을 pdf·오피스까지 넓혔을 때 같이 안 넓어졌다. 같은 앱 안에서 검색 두 개가 서로 다른 결과를 내는 상태.
- **방향**: 즉석 검색도 FTS5 색인을 타게 하거나, 최소한 범위 차이를 화면에 알릴 것.

### 5. 백그라운드 재색인 진행 표시가 없다

- **왜**: 1회성 재색인이 도는 동안 아무 표시가 없어서 멈춘 것처럼 보인다. 동작 자체는 정상.
- **어디**: `SearchIndexer.reindex` 호출부 · 기존 `onChunk` 진행 콜백 재사용 가능(`NoteIndexService.buildIndex`가 1만개 단위로 이미 쓰고 있음).
