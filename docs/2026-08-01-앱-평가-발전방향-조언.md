- **"정부지원사업 사건철+제출 전 검수관"에 대해**: 세 곳 다 "보류가 맞다"에 동의.

## 1. codex(gpt-5.6-sol) 답변

### 평가
- 제품 상태: 매우 좋음. 읽기→검색→AI질의→정리라는 원래 목표가 실제로 이어짐.
  원본을 함부로 안 바꾸고 사람이 확인 후 실행한다는 안전 원칙이 개인 문서 앱에서
  기능 수보다 중요한 차별점.
- 코드 상태: 건강함(Swift 파일 345개, 앱코드 188+테스트 157). 다만 1,000줄 넘는
  파일이 여럿(`MarkdownRenderer.swift` 1,407줄·`SidebarView.swift` 1,184줄·
  `SettingsView.swift` 1,098줄·`VaultManagerView.swift` 1,045줄) — 당장 문제는
  아니지만 계속 커지면 수정이 어려워질 수 있음.
- 테스트: 내부 로직은 잘 검사되지만 화면 모양·마우스 동작은 여전히 사람 확인 의존.

### 위험 신호·기술부채
1. **개발 속도가 너무 빠름** — 최근 30개 커밋에서 약 6,746줄 추가.
2. **kordoc이 `@latest`로 고정 없이 호출됨** — 앱 코드를 안 바꿔도 kordoc 최신판이
   바뀌면 HWP 읽기·쓰기 결과가 달라질 수 있음. 검증한 버전을 고정하고 새 버전은
   따로 시험 후 올리는 방식을 권함.
3. **문서가 실제 상태를 못 따라감** — `CLAUDE.md`는 v0.9.425·검사 1,068개로 적혀
   있는데 실제는 v0.9.428·1,289개. README는 993개.
4. **배포 공증 여부 안내가 서로 충돌** — 작업기록은 v0.9.428이 공증됐다고 적는데
   README·CLAUDE.md는 비공증이라고 안내. 실제 산출물 확인 후 문구 통일 필요.
5. **저장 안 된 내용 유실 위험** — 강제종료 사고 기록 있음, 자동저장 기본 꺼짐.
6. **포크가 업스트림보다 655개 커밋 앞섬** — 나쁜 건 아니지만 "독립 앱"이 됐다고
   보는 게 정확함.

### 발전 방향 (우선순위)
1. 학습도우미 S2 "오늘 복습할 것"(최우선)
2. **"작업 바구니"/"자료 묶음"** — 사건철보다 범용적. 서로 다른 폴더 파일을 옮기지
   않고 한 바구니로 묶어 검색·자료묻기·비교·나란히보기·학습도우미를 실행. 첫 버전은
   "파일 바로가기 목록 저장"부터 작게 시작 가능.
3. **"새 파일 수신함"** — 다운로드·데스크탑 등에 새 파일 생기면 모아서 미리보기+
   중복확인+PARA 목적지 추천+이름변경 제안 → 배치 정리. 기존 파일감시·PARA추천·
   배치이동·되돌리기를 재사용.
4. **"문서 변화 레이더"** — 지정 파일 수정 시 이전 내용과 비교해 추가/삭제/변경
   요약. 계약서·공고문·기획서에 공통 사용.
5. **문서에서 "할 일과 날짜" 꺼내기** — 마감일·할일·담당자 후보를 출처와 함께 목록으로.
   자동 캘린더 등록보다 먼저 확인 화면부터.

### 당분간 미루는 것
- 뜻으로 찾기(의미 검색): 임베딩 도입 비용 대비 당장 이익 제한적.
- 사건철+검수관: 요구사항 미확정, 보류 타당.
- 복잡한 학습 통계·연속기록: 단순 복습함 먼저 실제 사용 확인.
- HWPML 등 희귀 형식 계속 추가: 기존 흐름 완성도가 더 중요.

### 추천 순서
1. 문서 숫자·배포 안내 정리, kordoc 버전 고정, 저장 유실 방어
2. 학습 대화 임시 복구 기능 마무리
3. 학습도우미 S2 최소 복습함
4. 범용 "작업 바구니" 작은 버전 시험
5. 실사용 결과에 따라 "새 파일 수신함" vs "문서 변화 레이더" 택1

## 2. claude(claude-fable-5) 답변

- 문서·기록 습관 자리잡음 — 7/31 대청소로 CLAUDE.md 153KB→5.2KB, todolist "지금"
  칸 0개(밀린 확인 4건 전부 처리 완료).
- 틀렸던 판단도 정정 과정을 남기는 습관(kordoc 구버전 캐시 오판 정정 사례 등).
- 속도: 최근 30일 커밋 449개 — 학습도우미 하루 만에 S0→완성.

### 위험 신호·기술부채
1. **속도가 빠른 게 장점이자 위험** — "S1 실사용 3회 후 판정" 관문을 건너뛰고
   바로 S3 착수한 사례. 관문을 세워놓고 건너뛰는 게 습관 되면 관문 의미 없어짐.
2. **미완성 조각**: 학습도우미 대화 크래시 복구 임시저장(StudyChatDraftStore)
   아직 미구현 — 지금은 대화 중 앱 꺼지면 대화 사라짐.
3. **문서 숫자가 벌써 낡음** — CLAUDE.md v0.9.425·1,068개(실제 v0.9.428·1,289개),
   README 993개. 매일 변하는 숫자를 문서에 적으면 반드시 낡는다는 신호.
4. **외부 도구 의존은 구조적 약점이나 잘 관리됨** — 도구 없으면 안내만 뜨고 안 죽음.
5. **원본(CmdMD)과 점점 멀어짐** — 절반 이상이 포크 고유 기능, 사실상 독립 앱.
6. **가끔 이유 없이 실패하는 검사 1개**(AppIndexSearchTests, 타이밍 문제) — 무해하나
   방치하면 "실패 무시하는 습관"으로 번질 수 있음.

### 발전 방향
1. **학습도우미 "복습" 기능(최우선)** — 이미 절반 심어진 씨앗(S2).
2. 다지기 3종: 대화 임시저장 마무리 / 낡은 문서 숫자 정리 / 가끔 틀리는 검사 손보기.
3. **"오늘 화면"** — 앱 열면 오늘 복습할 카드·최근 본 문서·마지막 교재·최근 대화가
   한눈에 모이는 첫 화면(복습 기능 나온 다음에 붙이면 딱 맞음).
4. 사건철 재개 시: "폴더 안 서류에서 날짜·마감 표현만 자동으로 뽑아 한 목록으로
   보여주기"부터(판단 없이 뽑아 보여주기만 하므로 결정할 게 거의 없음).
5. 그 외 후보(급하지 않음): 자주 하는 검색 저장하기 / 다른 사람용 첫 실행 안내 /
   뜻으로 찾기(의미 검색).

## 3. kimi(moonshot-ai/kimi-k2.7-code) 답변

### 평가
- 목표가 명확해짐(2026-07-30 방향 결정: 파일관리자·공개배포·앱 안 위키 셋 다 계속
  키움). 릴리스가 살아있음(v0.9.428, 자동 업데이트 확인됨). 테스트 문화 단단함
  (57→1,289개, Phase 게이트 준수). 문서 정리 깔끔함.
- 핵심 기능이 유기적으로 어우러짐 — 읽기·검색·AI·파일관리가 원래 목표를 거의
  다 커버.

### 위험 신호·기술부채
1. **수동 실사용 검증 병목** — 기능 늘수록 "레고가 직접 눌러봐야 통과"하는 항목
   쌓임. 8/1에야 4건을 한꺼번에 처리.
2. **외부 도구 의존** — kordoc(Node 18+)·claude CLI 설치·로그인 필수, 진입장벽.
   kordoc 버전 캐시로 실제 오판 1건 있었음.
3. **배포 인증(ad-hoc 서명) 문제 여전** — 다른 사람 맥에서 Gatekeeper 경고. 유료
   인증서는 2026-07-31에 "안 산다"로 확정됐으니 "알고 가는 리스크".
4. **기능 범위 팽창 속도** — 최근 30개 커밋 대부분이 학습도우미(S0→S3)에 집중.
   지금은 테스트·문서로 버티지만 "무엇을 안 할까" 정하는 게 점점 중요해질 것.
5. **아직 못 여는 것**: `.hwpml`(보류) / 의미검색(임베딩) 미구현 / 학습도우미
   대화 크래시 복구 임시저장 미구현.
6. **기술부채는 관리되는 중**: AppState.swift 4,508줄→13개 파일 분리, 렌더링
   자산 로컬화(highlight.js·KaTeX·Mermaid), 신규 기능 별도 파일 분리 원칙 유지.

### 발전 방향
1. **학습도우미 복습 일정(최우선)** — 이미 노트에 `due`·`ivl`·`ease`·`reps`·
   `lapses` 필드가 들어가는데 이걸 보여줄 화면이 없음.
2. **뜻으로 찾기(의미검색)** — 큰 그림이지만 착수 전 결정 필요. 가벼운 길
   (`NLContextualEmbedding` CJK, 설치 불필요)과 무거운 길(Ollama `bge-m3`, 고품질
   but 설치 부담) 두 옵션 제시.
3. **문서 비교(diff) 보기** — 계약서·공고문 "이전 버전과 뭐가 바뀌었지?"를 화면에서
   나란히 색으로 강조 표시. 기존 ContentExtractor 재활용 가능.
4. **지식 그래프/노트 관계도** — 위키가 앱 안 정식 기능이 됐으니, 마크다운 링크를
   시각적으로 보여주는 화면. 학습도우미 카드와도 연결 가능.
5. **PDF/이미지 형광펜·메모 주석** — 원본 안 건드리고 사이드카 파일(짝꿍 노트
   패턴 재사용)에 저장, Dropbox/iCloud 동기화 안전.
6. **빠른 파인더 마무리(조각 E)** — 폴더 오갈 때 화면 전환 매끄럽게. 큰 기능
   아니라 "닦아내는" 작업.
7. **macOS 단축어(Shortcuts)/메뉴바 위젯 연동** — Finder에서 선택한 채로 단축어로
   cmdALL 검색 인덱스 추가 등. 비샌드박스 제약 고려해 범위 신중히.

### 보류 유지
- 사건철+검수관: "지금 당장 코딩은 낭비" — 어떤 서류가 한 사건인지, 마감일·체크
  리스트를 누가 입력하는지 미정.
- HWPML: 희귀 형식, 실제 파일 나올 때까지 대기.
